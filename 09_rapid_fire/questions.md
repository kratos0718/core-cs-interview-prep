# Rapid-Fire One-Liners — 20 Questions

The quick "what is X in one line" volley recruiters fire to test breadth. Crisp answers — say them fast and confidently. (Deeper versions are in the subject files.)

---

**1. ⭐ What is an API?**
A defined interface that lets two software components communicate — you call its methods/endpoints without knowing the internal implementation.

**2. ⭐ What is REST?**
An architectural style for web APIs using HTTP methods on resources (URLs), stateless requests, and standard status codes — typically returning JSON.

**3. ⭐ What is JSON?**
JavaScript Object Notation — a lightweight, human-readable text format for structured data (key-value pairs and arrays), the standard for web APIs.

**4. ⭐ What is the difference between authentication and authorization?**
**Authentication** = verifying *who you are* (login). **Authorization** = verifying *what you're allowed to do* (permissions). AuthN before AuthZ.

**5. ⭐ What is a primary key?**
A column that uniquely identifies each row in a table — unique and not null.

**6. ⭐ What is normalization?**
Organizing database tables to reduce redundancy and avoid anomalies, by splitting data into related tables.

**7. ⭐ What is Big-O notation?**
A way to describe how an algorithm's time or space grows with input size, in the worst case — measures scalability.

**8. ⭐ What is the difference between a stack and a queue?**
Stack = LIFO (last in, first out). Queue = FIFO (first in, first out).

**9. ⭐ What is recursion?**
A function that calls itself to solve smaller subproblems, with a base case to stop.

**10. ⭐ What is polymorphism?**
The ability of the same interface/method to behave differently depending on the object — "many forms."

**11. ⭐ What is encapsulation?**
Bundling data and methods into a class and restricting direct access to the internals (via private fields + getters/setters).

**12. ⭐ What is a deadlock?**
A state where processes/threads are each waiting for a resource the other holds, so none can proceed.

**13. ⭐ What is a thread?**
The smallest unit of execution within a process; threads of a process share its memory.

**14. ⭐ What is virtual memory?**
An abstraction giving each process the illusion of a large private memory, using RAM + disk, larger than physical RAM.

**15. ⭐ What is the difference between TCP and UDP?**
TCP = reliable, ordered, connection-oriented (slower). UDP = fast, connectionless, no delivery guarantees.

**16. ⭐ What is DNS?**
The system that translates domain names (google.com) into IP addresses.

**17. ⭐ What is HTTP?**
The protocol browsers and servers use to exchange web data; stateless, request-response. HTTPS is its encrypted version.

**18. ⭐ What is caching?**
Storing frequently-used data in a fast layer so repeat access skips the slow source — reduces latency and load.

**19. ⭐ What is an index (in a database)?**
A data structure (usually a B+ tree) that speeds up lookups on a column, at the cost of slower writes and extra storage.

**20. ⭐ What is the difference between SQL and NoSQL?**
SQL = structured tables, fixed schema, ACID, scales vertically. NoSQL = flexible/schemaless, scales horizontally, often eventual consistency.

## How to handle the rapid-fire round
- **One clean sentence**, then stop. Don't ramble.
- If you blank: *"It's [category] — give me a second... it's used for [purpose]."* Reasoning beats freezing.
- These 20 cover the most-fired ones. If you can say all 20 smoothly, you'll sound sharp and broad.
