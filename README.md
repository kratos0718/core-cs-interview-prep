## How to use this

- **Have a week?** Read in order, one subject per day. Understand the explanations.
- **Interview tomorrow?** Open the relevant subject, read the ⭐ questions, then the rapid-fire file.
- **Practising out loud?** Cover the answer, say yours, then compare. Speaking beats reading.

## How to answer in the room (meta-advice)
1. **Define the term** in one clean sentence first.
2. **Give the why / an example** — this is what separates you.
3. **Stop.** Don't ramble. Let them ask the follow-up (you're ready for it).
4. If you don't know: *"I'm not certain, but my reasoning would be..."* — reasoning earns more than silence or bluffing.

## Note on honesty
These are genuine, commonly-asked questions with correct, standard answers. Verify anything you're unsure of against a textbook (Galvin for OS, Korth for DBMS, Tanenbaum/Kurose for Networks, Cormen for DSA) — but this covers the 95% recruiters actually ask freshers.
